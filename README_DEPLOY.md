# GDS 배포 체크리스트 (README_DEPLOY.md)

모든 랜딩페이지 · GO 페이지는 **수정 후 아래 순서대로** 배포합니다.  
순서를 건너뛰면 로컬과 라이브가 달라지거나, 브라우저 캐시로 변경이 안 보일 수 있습니다.

---

## 배포 전 체크리스트 (필수 순서)

### 1. Keep All
- Cursor / IDE에서 제안·변경 사항을 **Keep All**로 확정합니다.
- 미적용(Reject) 상태인 수정이 남아 있지 않은지 확인합니다.

### 2. Ctrl + S
- 수정한 모든 파일을 **저장**합니다. (`Ctrl + S`)
- 여러 파일이면 전부 저장되었는지 확인합니다.
  - 예: `index.html`, `css/style.css`, `shared/*.css` 등

### 3. FileZilla 업로드
- FileZilla로 **변경된 파일만** (또는 해당 페이지 폴더) 서버에 업로드합니다.
- 로컬 경로와 서버 경로가 맞는지 확인합니다.
  - GO 예: 로컬 `gds-go/` → 서버 `/go/`
- 업로드 후 FileZilla 전송 완료·실패 로그를 확인합니다.

### 4. Ctrl + F5
- 배포 URL을 연 뒤 **강력 새로고침**합니다. (`Ctrl + F5`)
- 일반 새로고침(`F5`)만 하면 예전 CSS가 남을 수 있습니다.

### 5. 브라우저 확인
아래를 실제 화면에서 확인합니다.

- [ ] 레이아웃·디자인이 의도대로인지
- [ ] CTA 버튼 색상·링크(카카오 / 전화)
- [ ] Footer · 저작권 문구
- [ ] 모바일 / 데스크톱 모두 확인
- [ ] 개발자 도구 → Network에서 CSS가 **최신 파일**로 로드되는지

### 6. Search Console 필요 여부 확인
아래 중 하나라도 해당하면 Search Console 작업을 검토합니다.

| 변경 내용 | 권장 조치 |
|-----------|-----------|
| 신규 랜딩 공개 | URL 검사 → 색인 생성 요청 |
| `title` / `description` / canonical 변경 | URL 검사로 반영 확인 |
| URL 경로 변경·이동 | 이전 URL 처리 + 새 URL 색인 |
| `sitemap.xml` 변경 | 사이트맵 제출/갱신 |
| 문구·버튼 색만 변경 (URL 동일) | 보통 **불필요** (선택 사항) |

---

## 빠른 복사 체크리스트

```
[ ] 1. Keep All
[ ] 2. Ctrl + S (전체 저장)
[ ] 3. FileZilla 업로드 완료
[ ] 4. Ctrl + F5
[ ] 5. 브라우저 확인 (PC + 모바일)
[ ] 6. Search Console 필요 여부 판단
```

---

## 참고

- 로컬에서만 보이고 라이브에 없으면 → **3. FileZilla 업로드**가 빠진 경우가 많습니다.
- 업로드했는데 색이 안 바뀌면 → **4. Ctrl + F5**를 다시 진행합니다.
- 공통 컴포넌트(`shared/`)를 수정한 경우, 그 파일을 쓰는 **모든 페이지 경로**에 업로드가 필요한지 확인합니다.
